# Mohammad Asif Zafar - Portfolio & Engineering Blog

Welcome to the official repository for Mohammad Asif Zafar's personal portfolio website and web-based Engineering Blog platform.

Live Website: [https://mohammad-asif-zafar.github.io/](https://mohammad-asif-zafar.github.io/)

---

## Architecture Overview

- **Portfolio Homepage:** [`index.html`](file:///Volumes/DevelopmentSSD/Android/Projects/GitHub/mohammad-asif-zafar.github.io/index.html) - Senior Android Engineer Portfolio (Kotlin, Jetpack Compose, KMP, Experience, Audio Intro, Projects).
- **Public Blog:** [`blog/index.html`](file:///Volumes/DevelopmentSSD/Android/Projects/GitHub/mohammad-asif-zafar.github.io/blog/index.html) & [`blog/post.html`](file:///Volumes/DevelopmentSSD/Android/Projects/GitHub/mohammad-asif-zafar.github.io/blog/post.html) - Integrated engineering blog with live search, category/tag filtering, and code syntax highlighting.
- **Web Admin CMS:** [`admin/index.html`](file:///Volumes/DevelopmentSSD/Android/Projects/GitHub/mohammad-asif-zafar.github.io/admin/index.html) - Private web-based markdown editor, live preview, image uploader, draft system, and GitHub API content manager.
- **Content Store:** `content/blog/*.md` - Version-controlled Markdown articles with YAML frontmatter.
- **Automation & Deployment:** `.github/workflows/deploy.yml` & `scripts/build-blog.js` - Automated GitHub Actions workflow generating `posts.json`, `sitemap.xml`, and `feed.xml` (RSS).
